# AI-Powered Healthcare Diagnosis Assistant

## Overview
An AI-powered web application built using Machine Learning and Google Gemini AI that predicts diseases based on user-selected symptoms and provides AI-generated health advice.

## 🚀 Live Demo

🔗 https://khushi325-ai-powered-healthcare-diagnosis-assistant-app-vxpumz.streamlit.app/

## 📂 GitHub Repository

🔗 https://github.com/khushi325/AI-Powered-Healthcare-Diagnosis-Assistant

---

## Features
- Disease Prediction using Logistic Regression
- AI Health Advice using Google Gemini
- PDF Report Generation
- Prediction History
- Interactive Streamlit Interface

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Google Gemini API
- ReportLab
- Pandas
- NumPy

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
