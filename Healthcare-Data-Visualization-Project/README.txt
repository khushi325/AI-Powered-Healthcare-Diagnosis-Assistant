Project Title:
Healthcare Disease and Symptom Analysis Dashboard

Tools Used:
- Power BI Desktop
- CSV Dataset

Dataset Information:
- Total Records: 246,945
- Total Columns: 378
- Disease Column: diseases

Dashboard Features:
- Top 10 Diseases Associated with Anxiety
- Top 10 Diseases Associated with Depression
- Anxiety vs Depression Comparison
- Top 10 Diseases Associated with Insomnia
- Top 10 Diseases Associated with Dizziness

Objective:
To analyze disease-symptom relationships using interactive Power BI visualizations.
